# Termux עם RTL

טרמינל Termux לא תמך ב־BiDi, ולכן עברית וערבית נמצאות במסך **מהופכות**.
כאן יושבת תיקון שנבנה כחלק מהטרמינל עצמו: השורות שמכילות טקסט מימין לשמאל
מסודרות לפי UAX#9, אותיות ערבית מתחברות, סוגריים מתהפכים לפי כלל L4, והסמן נמצא
במקום הנכון — גם בזמן הקלדה. אין שום פקודה להריץ, זה עובד בכל מקום ובכל סוכן קוד.

## התקנה

1. הורד את ה־APK המתאים למכשיר שלך:
   - **רוב הטלפונים** (ארמ64):
     [termux-apk-arm64-v8a.apk](https://github.com/shmuelr16/termux-rtl/releases/latest/download/termux-apk-arm64-v8a.apk) — 38MB
   - **כל מכשיר** (כולל x86 ו־32 ביט), הקובץ הגדול:
     [termux-apk-universal.apk](https://github.com/shmuelr16/termux-rtl/releases/latest/download/termux-apk-universal.apk) — 125MB
2. פתח את הקובץ ולחץ "התקנה". הוא מחליף את ה־Termux הקיים **בלי למחוק את הקבצים
   שלך**, כי הוא חתום באותו מפתח בדיוק (מפתח הבדיקות של AOSP — כמו בגרסאות
   F-Droid ובגרסאות שנבנו מהקוד).
3. זהו. לא מריצים שום דבר, ולא מגדירים שום פקודה — העברית עובדת מיד, גם בזמן
   ההקלדה וגם בפלט של כל סוכן קוד.

### אם מותקנת לך הגרסה מ־Google Play

הגרסה של Play חתומה במפתח אחר, ולכן Android לא יאפשר להתקין מעליה.
אפשרויות:
- עברו לגרסת F-Droid והתקינו אותה **לפני** שמתקינים את ה־APK כאן — אז ההתקנה
  מתעדכנת במקום ושומרת הכל.
- או: גבו את התיקייה `~/` שלכם, הסירו את הגרסה מה־Play, והתקינו את ה־APK כאן.

## מה התיקון עושה

- `BidiLayout` – מחשב את הסדר הוויזואלי של כל שורה לפי אלגוריתם BiDi
  (`android.icu.text.Bidi` באנדרואיד 7 ומעלה, ואלגוריתם פשוט לגרסאות ישנות).
- `ArabicShaper` – מחבר אותיות ערבית לצורות הצגתן ההקשריות.
- `BidiMirror` – הופכת סוגריים וסוגריים מרובעים בתוך רצועות RTL (כלל L4).
- `TerminalRenderer` – מצייר כל אשכולת בעמודה הוויזואלית שלה ומצייר את הסמן
  בעמודה הוויזואלית של העמודה הלוגית של הסמן.

שורות ללא טקסט RTL נמשכות באותו מסלול מהיר כמו קודם — השינוי חל רק כשצריך.

## בנייה עצמית

ה־APK נבנה אוטומטית ב־GitHub Actions מתוך `termux/termux-app`
(commit `8629e63`) + `patches/termux-bidi.patch`:

```sh
git clone --recursive https://github.com/shmuelr16/termux-rtl
cd termux-rtl && gh workflow run build-apk.yml
```

## מגבלות ידועות

- שורה אחת משתמשת ברמת embedding אחת — כמו ברוב הטרמינלים.
- עורכים מלאים (vim, nano) עם ממשק מרובה שורות לא נמצאים מתוקנים.
- אותיות ערבית מצורפות לפי תקן Unicode; תצורת האותיות בפונט נשארת לפונט.
